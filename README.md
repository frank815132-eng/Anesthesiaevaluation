# 麻醉評估問卷（術前病人自填）

一個給病人在平板上自行點選的術前麻醉評估問卷。純前端單一 HTML 檔案，不需要伺服器、不儲存任何資料。

**免責聲明**：本工具僅作為術前訪視的提醒與資料收集輔助，**不取代正式的麻醉評估與病歷紀錄**。所有內容仍須由麻醉科醫師當面確認。

---

## 使用方式

1. 用平板（建議直式）開啟網頁
2. 交給病人，點「開始作答」
3. 病人依序回答 7 題，選完會自動或按「下一題」前進
4. 完成後畫面顯示「完成問卷，將平板給醫師」及結果總表
5. 醫師看完總表後，按右下角小字「下一位病人（清除重填）」重置

所有答案只存在瀏覽器記憶體中，**重新整理或關閉分頁即消失**，不會上傳任何地方。

---

## 設計重點

- **一題一畫面**：版面固定為一個螢幕高，病人不需要捲動，避免漏答下方題目
- **單選題自動跳下一題**；複選題與需要思考的題目（如減重針劑）保留「下一題」按鈕，讓病人有改答案的機會
- **「沒有」為互斥選項**：勾選後自動清除其他選項，避免出現「沒有過敏 ＋ 藥物過敏」的矛盾答案
- **大字大按鈕**：字級隨螢幕尺寸放大，選項按鈕自動撐滿可用高度，適合年長病人
- **紅框警告語**：涉及手術取消的衛教項目以紅字紅框強調
- **總表一眼看完**：不需捲動，需要注意的項目以紅底標示

## 如何修改題目

所有題目都寫在 `index.html` 最上方的 `STEPS` 陣列裡，改這一段就好，不必動其他程式碼。

```js
{ key:"過敏",              // 結果總表上顯示的標籤
  type:"multi",           // multi=複選, single=單選, notice=衛教提醒
  q:"有藥物或食物過敏嗎？",   // 題目
  sub:"可以複選",           // 副標（可省略）
  opts:[
    { pre:"有", t:"藥物過敏", e:"💊", flag:1 },
    { pre:"沒有", t:"過敏",   e:"🙂", none:true }
  ] }
```

各欄位意義：

| 欄位 | 說明 |
|------|------|
| `key` | 結果總表左側的標籤文字 |
| `type` | `multi` 複選／`single` 單選／`notice` 衛教提醒 |
| `hold` | 加在 `single` 題上，表示選完**不要**自動跳頁，要按「下一題」 |
| `t` | 選項文字 |
| `pre` | 選項前的「有／沒有」色塊標籤（可省略） |
| `e` | 選項的圖示 emoji |
| `flag` | 設為 `1` 時，此選項會在結果總表以紅底標示 |
| `none` | 設為 `true` 時，此選項與同題其他選項互斥 |
| `lines` | `notice` 題的內文（陣列，可為空） |
| `warn` | `notice` 題的紅框警告語（可省略） |
| `btn` | `notice` 題的按鈕文字 |

新增一題就在陣列裡加一個物件，順序即畫面順序，進度條會自動跟著調整。
